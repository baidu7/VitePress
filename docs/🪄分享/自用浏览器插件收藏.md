**超级复制**
一键破解禁止右键、破解禁止选择、破解禁止复制、破解禁止粘贴，启用复制，启用右键，启用选择，启用粘贴。
特性：
1. 一键破解js方式的禁止复制网站。
2. 一键破解css方式的禁止复制网站。
3. 具有记忆功能，下次打开相同页面自动破解禁止复制。
4. 具有联想功能，打开同站点其他页面自动破解禁止复制。
